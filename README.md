# Controle de vendas
Projeto desenvolvido durante o 2º termo do curso de Análise e Desenvolvimento de Sistemas para Interfocus, com foco na criação de uma solução colaborativa desde a concepção até a implementação.

### Sobre o Projeto

Este projeto consiste em um sistema de controle de vendas e gestão de fiado desenvolvido para uma vendinha local. A solução tem como objetivo facilitar o registro de vendas, o acompanhamento de débitos de clientes e a organização do caixa do estabelecimento.

### Tecnologias Utilizadas

* **Front-end:** HTML + CSS
